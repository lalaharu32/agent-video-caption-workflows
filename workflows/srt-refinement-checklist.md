# SRT Refinement Checklist

Use this checklist when refining SRT files generated by speech-to-text tools.

## Principles

- Do not change subtitle numbers unless you intentionally restructure the file
- Do not change timestamps unless the timing is clearly wrong
- Do not summarize or rewrite the meaning
- Fix obvious recognition errors and missing small words
- Preserve speaker tags when they exist
- Save refined subtitles as a new file instead of overwriting the original

## Per-Entry Review

Check each subtitle entry.

- Is the text natural to read?
- Are there obvious speech recognition errors?
- Is a particle, pronoun, or short word missing?
- Is the subtitle too long to read comfortably?
- If a line break exists, does it avoid splitting words or phrases?
- Is the text empty?

## Whole-File Review

Check the full file after editing.

- The original and refined SRT files have the same entry count
- The final timestamp was not accidentally dropped
- Subtitle numbers do not skip unexpectedly
- Timestamps do not move backward
- No extremely long subtitle remains
- Repeated recognition errors were fixed consistently

## Report Template

```text
SRT refinement complete
- Entry count: 120 -> 120
- Final timestamp: 00:12:34,000
- Empty subtitles: 0
- Reversed timestamps: 0
- Main edits: recognition errors, punctuation, readability
```
