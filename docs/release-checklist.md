# Release Checklist

公開前に確認する項目です。

- 個人環境の絶対パスが含まれていないこと
- 認証情報、配信先、実在する個人名が含まれていないこと
- 実案件の動画名や保存先が含まれていないこと
- FFmpegコマンドが汎用的なファイル名になっていること
- READMEのGitHub URLや説明が公開先と合っていること
- サンプルSRTとASSが架空の内容だけで構成されていること

ai-agents, video, subtitles, srt, ass, ffmpeg, workflow, codex, documentation
