# Release Checklist

Check these items before publishing a release.

- No private filesystem paths are included
- No credentials, destination URLs, or real personal names are included
- No real project video filenames are included
- FFmpeg commands use generic filenames
- Sample SRT and ASS files contain fictional text only
- README links and repository description match the public repository

Recommended topics:

```text
ai-agents, video, subtitles, srt, ass, ffmpeg, workflow, codex, documentation
```
